## 1. Project Purpose & Mental Model

AI-powered tool and MCP server that makes unfamiliar codebases understandable to humans. Built on foundational ideas and schemas from Understand-Anything (Egonex-AI) and Repomix.

### Mental Model
Think of **feinman** like a well-organized clockwork workshop: the **entrypoints** accept external inputs (commands, clicks, or HTTP requests) and direct them to specialized workbenches (CLI & Entrypoints, API & Routing Layer, Core Logic & Intelligence, UI & User Experience, MCP & Agent Skills, Utilities & Configuration). Each part does one job with clear boundaries, ensuring that changes to the user interface or external adapters do not disrupt the core algorithms underneath.

## 5. How to Make Changes Safely

When modifying this codebase, follow the Feinman 4-step change discipline:
1. **Identify the Core Workbench**: Check which subsystem owns the logic.
2. **Inspect Downstream Blast Radius**: Find which files import the target module before modifying exported signatures.
3. **Keep Interface Boundaries Intact**: Don't leak implementation details across subsystems.
4. **Run Verified Tests**: Execute `npm test` to verify that existing contracts remain valid.
